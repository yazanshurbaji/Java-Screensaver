# Java Screensaver

A Java screensaver application that displays geometric shapes using Java Swing and object-oriented programming.

## About the Project

This project demonstrates the use of Java graphics and object-oriented programming to create a screensaver application.

The application uses different classes to represent and draw geometric shapes.

## Technologies Used

- Java
- Java Swing
- Java AWT
- Object-Oriented Programming (OOP)
- IntelliJ IDEA

## Features

- Displays different geometric shapes.
- Uses Java Graphics2D for drawing.
- Implements inheritance and polymorphism.
- Organizes shapes into separate Java classes.

## Project Structure

The `src` folder contains the Java source files:

| File | Description |
|------|-------------|
| Main.java | Entry point of the application |
| Shape.java | Base class for geometric shapes |
| CircleShape.java | Draws circles |
| SquareShape.java | Draws squares |
| TriangleShape.java | Draws triangles |
| StarShape.java | Draws stars |
| ScreensaverFrame.java | Application window |
| ScreensaverPanel.java | Panel used to display shapes |

## How to Run

1. Download or clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure the Java Development Kit (JDK).
4. Open `Main.java`.
5. Run the application.
